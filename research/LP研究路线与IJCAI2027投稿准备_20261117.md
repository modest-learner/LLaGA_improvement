# 1. 研究定位与核心决策

本研究以 LLaGA 为可运行基线，研究同任务、零样本跨图链接预测（LP→LP）：在源图上用链接预测监督训练模型，直接预测未参与训练的目标图中的链接。目标图的测试标签不用于训练、模型选择或阈值调整。

**核心问题：在同任务跨图链接预测中，邻域信息何时提供超出端点语义的可迁移增益，何时产生干扰，以及如何让这种增益在未见图上更加稳定？**

“跨图泛化”是研究目标；“端点语义与邻域信息”是研究对象；“单源／多源”和“同领域／跨领域”是检验条件。最终贡献应围绕同一个问题组织，避免把不同实验条件发展成互不关联的研究主题。

当前从 Arxiv＋Pubmed → Cora 的多源引文网络实验继续，补单源机制对照和其他目标图；建立稳定证据后，提出针对性改进，再考虑电商内部与跨领域验证。NC→NC 是后续扩展，节点描述→节点分类不属于当前 LP 主线。

## 1.1 零样本的具体含义

目标图可以提供预先约定的节点文本和可见上下文边，但不使用目标监督候选的答案进行优化。使用可见图作为输入，与在目标图上优化模型参数是两件事；若后续使用目标无标签数据优化参数，需要单独标为目标适应。

LP 的输出空间始终是“有边／无边”。当前主要研究图和数据分布变化，不研究 NC 中类别体系改变。跨领域时，引用、共同购买、共同浏览等边可能表达不同关系，必须另外说明关系含义变化。

## 1.2 论文定位

工作方向可表述为“面向同任务跨图链接预测的语义与邻域信息迁移研究”。正式题目应在主要机制和方法明确后确定，不能预先宣称已经发现普遍缺陷或已经解决某种失效。

# 2. 研究动机与研究问题

## 2.1 为什么值得研究

较好的跨图准确率没有直接说明模型迁移了什么。LLaGA 的输入包含中心节点文本语义和多跳邻域聚合表示，LLM 还具有预训练语言知识。高分可能来自端点语义、邻域关系，也可能受到候选难度和评测协议影响。

源图与目标图在节点主题、连接规律、度分布、邻域组成和负例难度上均可能不同。只训练 Projector 能够迁移，不等于它必然学到了稳定、通用的图表示。因此需要先建立清洁协议，再通过匹配重训、简单强基线、输入干预和多目标验证，定位真正可迁移的信息与反复出现的失效条件。

## 2.2 三个递进问题

| 问题 | 要回答的内容 | 核心证据 |
|---|---|---|
| RQ1：哪些信息能够迁移？ | 真实邻域是否提供超出端点语义的稳定增益？ | Full／Center-repeat 匹配重训、端点模型、结构基线 |
| RQ2：这种迁移何时失效？ | 什么样的语义、邻域或候选分布变化与错误相关？ | 错误分组、控制实验、单源／多源、多目标复核 |
| RQ3：如何改善失效？ | 针对已确认问题的设计，能否提高未见图上的稳定性？ | 最小方法改进、机制消融、强基线与独立确认 |

三者构成“现象—解释—改进”的同一条研究线。多源是否优于单源只是 RQ2 的一个条件，不能同时把源选择、跨任务、输出格式、编码器替换全部设为独立主问题。

# 3. 当前已有证据与结论边界

本节依据项目中 2026 年 11 月 17 日已完成并审计的分析报告。正在执行的 source、baselines、seeds 阶段不在本文中假定已全部完成；新增结果需要另行汇总。

## 3.1 已有研究基础

已完成官方结果复现探索、数据与缓存及评分审计、独立清洁 LP 视图、统一冻结 BERT 特征，以及 seed42 的 Full／Center-repeat 两组匹配训练。当前工作配置为冻结 BERT、冻结 Vicuna、HO 四跳、Linear Projector、学习率 2e-3、有效 batch size 16、一个 epoch。

该配置是当前研究工作基线，并非声称它在所有图上最优。新旧协议同时改变了编码器、数据清理和上下文规则，不能把新旧指标差异单独归因某一因素。

## 3.2 清洁协议下的关键结果

源图为 Arxiv＋Pubmed，目标为 Cora；测试集合为 651 个唯一候选节点对，其中 274 个正例、377 个负例。以下是单训练种子 seed42 的结果。

| 训练输入 → 测试输入 | 正确数 | ACC |
|---|---|---|
| Full → Full | 525／651 | 80.65% |
| Center-repeat → Center-repeat | 457／651 | 70.20% |
| Full → Center-repeat | 465／651 | 71.43% |
| Center-repeat → Full | 439／651 | 67.43% |

匹配比较的净增益为 68 个正确预测，即 10.45 个百分点。其中 106 对样本由中心模型错误变为 Full 正确，38 对相反。四组回答的二元解析有效率均为 100%。

**支持的结论：当前配置下，真实邻域聚合信息对未见 Cora 图上的 LP 有帮助。**

**尚不支持的结论：增益完全来自纯拓扑；现象适用于所有图；多源必然优于单源；主要错误已被证明源于跨图分布变化。** HO 同时包含邻居文本、边选择、归一化和多跳传播作用，尚未把这些因素完全拆开。

## 3.3 可追踪但未证实的失败假设

Full 的错误中，FP 为 102、FN 为 24。错误正预测的端点 BERT 相似度较高，提示“语义相似但无观测边”的候选可能是重要困难。但该描述没有控制度数、共同邻居等变量，不能直接视为因果证明，也不能据此立即确定方法。

原纯文本 LP 输出存在大量非明确二元回答，官方 yes 子串评分还会被 Bayes／Bayesian 触发。该分支不能用于直接估计结构贡献，也不能用低解析有效率断言文本没有判别信息。当前不重启大规模输出诊断支线。

原 HO 缓存按作者实际归一化规则复核后数值一致，不能称为缓存损坏。SimTeG 上游监督来源仍需独立审计，不能因为采用清洁 BERT 后分数下降就断言原结果已经确认存在标签泄露。

# 4. 统一实验协议与解释规则

1. **任务固定。** 源训练和目标测试均为 LP；目标不参与对应模型的监督训练。
2. **特征权限固定。** 各图使用同一冻结文本编码器、版本和预处理；不拼入类别标签。不直接替换现有 Projector 输入特征后解释性能，改变特征应重新训练。
3. **边可见性固定。** 当前协议规范无向候选，去重并排除自连接和已知伪负例；全部监督正边从上下文移除，训练查询自身也不可见。新图须先核对有向／无向含义。
4. **比较对象固定。** 同一目标上的模型使用相同候选集合、负例规则、提示和评分协议。随机负例与难负例分开报告，难负例生成规则提前确定。
5. **匹配重训优先。** Full 训练→Full 测试与 Center-repeat 训练→Center-repeat 测试比较信息增益。只改变推理输入属于敏感性诊断，可能带来分布外输入。
6. **模型选择只用源数据。** 阈值、超参数及早停依据源验证；目标标签用于最终计分。Cora 已反复查看，应作为开发目标，最终另留确认评估。
7. **统计单位清晰。** 主比较补独立训练种子；重复贪心推理不替代训练种子。逐边样本存在共享端点和结构依赖，不用大量边数冒充大量独立图。
8. **指标完整。** 报告 ACC、Balanced ACC、有效回答率、FP／FN 和成对差值；AUC／AP 需要连续分数，不能从现有硬标签 JSONL 恢复有意义的排序评价。

固定监督数量不等于固定全部可见上下文信息；源验证与目标测试候选难度不同，分差不能全部解释为图分布变化。所有归因均应写明这些限制。

# 5. 分阶段研究路线：做什么、为什么、做到何时

## 阶段一：完成当前多源基线的可靠性验证

完成 source、baselines、seeds：两种输入模型在源验证和 Cora 上的匹配评估；端点 BERT 余弦、端点 MLP 与 CN／AA／RA／PA；Full、Center-repeat 各补 seed43、44。

核心量为同一候选集上的邻域净增益：Δ = ACC(Full 匹配模型) − ACC(Center-repeat 匹配模型)。报告各训练种子差值和均值、样本标准差。

**进入下一阶段的依据：** 结果完整、配置可追溯，能够判断邻域增益是否稳定及简单方法的竞争力。如果种子波动大，先查不稳定原因；如果简单模型已经很强，后续方法必须与其比较。

## 阶段二：定位邻域帮助与干扰的条件

将同一候选对划分为两模型都正确、仅 Full 正确、仅 Center-repeat 正确、两者都错误四组。比较端点文本相似度、度数、共同邻居、中心与邻域相似度及不同 hop 表示差异，并分正负例分析。

先提出一至两个可证伪假设，再做控制实验。例如，若语义相似非边误报集中，需对照端点 MLP，并控制结构统计、负例难度及正负比例。高相似度本身可能只是难度指标。

**进入下一阶段的依据：** 找到有一定规模、能重复观察、可能由可操作因素解释的失败子集。原数据无观测边不一定意味着现实中绝无关系，结论限定在基准定义。

## 阶段三：以单源对照检查源图组合的作用

保持目标 Cora，比较 Arxiv→Cora、Pubmed→Cora、Arxiv＋Pubmed→Cora。当前多源是实验起点，单源用于定位信息来源，不需要放弃已有结果重新起步。

保留全量训练作为实用配置线；另建固定监督预算线：总计 M 条候选，单源各使用 M，多源各取 M／2，固定正负比、优化步数及训练配方。M 依据源数据可用数量确定，不依据 Cora 表现选择。已有全量多源权重不能代替预算匹配的多源模型。

先做最小 Full 三配置比较。只有要主张“源图组合改变邻域迁移增益”时，才为单源补齐 Center-repeat。多源低于某个单源，只能说明相对该单源退化；不能把测试集上最好的源当作实际可用的无标签源选择器。

**完成标准：** 能区分训练量效应与源组合效应，并如实报告上下文规模仍未完全匹配。主结论涉及的配置再补训练种子。

## 阶段四：增加目标图，确认机制可重复

优先 Arxiv＋Cora→Pubmed，分别训练 Full 与 Center-repeat；之后按证据和预算考虑 Pubmed＋Cora→Arxiv。各方向必须独立训练，不能把已参与模型训练的图作为该模型的零样本目标。

检查邻域净增益、错误类型、简单基线相对表现是否重复。目标不是所有图都出现相同提升，而是确定哪些输入或分布条件与收益相关。

**完成标准：** 关键现象至少获得额外目标证据。图轮换不自动消除开发偏差；记录各目标何时被查看，并预留未参与决策的确认目标。若前期现象可能是 Cora 特例，可将第二目标验证提前到单源矩阵之前，以避免无效扩张；这属于同一假设的优先级调整。

## 阶段五：围绕一个主要失败原因设计最小改进

| 若稳定证据支持 | 优先检验的改进方向 | 必须排除的替代解释 |
|---|---|---|
| 部分邻域持续干扰预测 | 基于输入可靠性的中心／多跳权重调节 | 额外参数、通用门控本身是否足够 |
| 高相似度非边误报突出 | 源语义难负例或成对判别训练 | 是否仅增加训练量或改变评测难度 |
| 节点独立表示难表达节点对关系 | 可迁移的成对结构信息 | 是否只是提供了额外可见边信息 |
| 某源加入后持续退化 | 先检查采样比例，再考虑源一致性约束 | 是否只是训练预算及源规模不平衡 |

这些是候选方向，不能预设一定有效。先核对最接近的已有研究，再做一个主要改动。方法应改善指定失败子集，并在总体性能、其他目标与计算成本上有可解释的结果。

**完成标准：** “失败证据→设计依据→机制消融→独立效果”闭合。没有明显证据时应修改或放弃假设，而非堆叠模块掩盖不确定性。

## 阶段六：构成论文级验证

补齐相关可运行强基线，如源训练 GraphSAGE＋边预测头；统一数据权限和模型选择规则，但不强迫不同架构使用完全相同学习率。比较 LLaGA、中心模型、端点语义模型及结构模型。

报告多个目标上的平均与最差表现、训练种子差异、关键消融、困难候选表现、额外参数与训练／推理成本。完整报告不利结果与适用范围，明确独立确认目标的角色。

## 阶段七：扩展电商内部，再研究跨领域

先核对 Computer、Photo、Children、History、Sports 等候选数据的版本、节点文本、边语义与跨数据集重复。预先划分开发和确认目标。

顺序为：引文→引文，电商→电商，引文→电商。电商内部迁移用于判断新目标本身是否困难；引文→电商检验更强分布和关系变化。所有方向仍固定 LP→LP。

进入这一阶段先冻结方法测试；看到电商结果后再改方法，则相关图成为开发数据，需另留确认目标。跨领域不是当前论文必须完成的硬性条件，也不能把同一方法换领域的结果自动拆成第二篇论文。

# 6. 控制研究范围与实际执行顺序

推荐主顺序：**当前多种子与基线 → 错误分组 → 固定预算单源／多源 → 第二引文目标 → 一个主要机制 → 最小方法改进 → 论文级确认 → 电商与跨领域。** 第二目标可在检验 Cora 特例时提前；不因此改变主问题。

每项新增实验必须写明：检验的假设、唯一主要改变的因素、保持一致的条件、预期支持或反驳假设的结果。一次不要同时改编码器、数据划分、提示和模型架构。

暂缓 NC、多任务节点描述监督、大规模编码器网格及无明确假设的模块组合。完整长期路线不是每篇论文的必做清单；以核心主张需要的证据确定范围。

单源与多源、同领域与跨领域都是实验条件。研究深度来自控制和解释，不来自实验数量。多种子与多个目标也不能互相替代。

# 7. 何时达到可撰写、可投稿的学术论文程度

## 7.1 基本判断

围绕跨图 LP 的一个明确失效机制，提出有新意的办法并提供充分证据，可以形成面向 IJCAI 的论文。只研究 LP 一个任务也可以，不必同时完成 NC、图分类和跨领域迁移。

“发现失败、修改模型、提高准确率”尚不自动构成完整贡献。需要说明研究增加了什么新的、可信且重要的知识或方法。方法论文可以很简洁，也不一定要求理论定理；但设计理由、创新差异和经验论证必须充分。

IJCAI 官方评审维度包括新颖性与原创性、正确性、清晰度、结果的重要性、潜在影响及呈现质量。官方未规定必须提升多少个百分点、必须多少数据集。[1][2]

## 7.2 四层成熟度

| 层次 | 代表性工作 | 判断 |
|---|---|---|
| 复现与工程验证 | 跑通、审计、修复加载及评分 | 研究基础，通常不单独构成方法贡献 |
| 现象发现 | 消融差异、某类样本失效 | 有研究线索，解释可能仍不充分 |
| 机制解释 | 控制主要因素，复核范围和替代解释 | 形成科学发现 |
| 方法与验证 | 针对原因提出新设计并独立验证 | 形成完整方法论文的核心 |

强分析或评测研究也可能形成论文，但需要其发现、严谨性和影响本身足够有价值。本项目目前倾向机制驱动的方法路线。

## 7.3 五个必须回答的问题

1. **问题重要吗？** 在合理条件下出现，影响有规模的样本或重要使用场景，不只是人为极端扰动。
2. **原因可信么？** 排除了评分、训练量、候选难度、输入分布外变化等主要替代解释；相关性不冒充因果。
3. **方法新在哪里？** 对最接近工作有明确差异，不能仅靠新增注意力、对比损失或难负例的名称说明创新。
4. **收益可靠吗？** 公平比较、强基线、多种子、多目标与机制消融形成一致证据；不能只依赖一个最佳数字。
5. **社区能得到什么？** 新认识、可复用解决原则或有竞争力的方法，以及可复查实验。

## 7.4 没有统一的性能门槛

单图单种子提升 3 个百分点只是线索；多目标稳定提升 1～2 个百分点并降低关键失败或成本，可能有实际价值；增加监督或改变负例后提高 5 个百分点不能直接归因方法。平均收益有限但最差目标显著改善，也可能构成稳健性贡献。

这些数字是说明性例子，不是录用阈值。统计显著不等于实际重要，指标高也不能替代原创性。会议接收仍由同行评审决定。

## 7.5 本项目的投稿准备检查表

| 维度 | 建议达到的状态 |
|---|---|
| 问题聚焦 | 一句话明确主张，所有主要实验服务它 |
| 新颖性 | 系统核对相关研究，说明实质差异 |
| 机制证据 | 多条件复核，排除主要混杂，限定结论范围 |
| 方法设计 | 设计与失败原因对应，关键组件可检验 |
| 强基线 | 语义、结构、图模型及相关图—LLM 方法合理覆盖 |
| 泛化证据 | 多目标与训练种子，保留确认评估 |
| 消融与效率 | 改善对应失败并说明额外成本 |
| 透明性 | 公开配置、评分规则、限制与不利结果 |

这是项目工作标准，不是会议官方的最低录用清单。三训练种子是当前预算安排，不保证结论普遍成立。可以现在开始整理本人撰写的研究草稿和论证结构，用写作发现证据缺口，不必等待全部实验完成。

## 7.6 当前所处位置

目前具备可信基础和邻域增益线索，但尚未形成完成的 IJCAI 方法论文。主要缺口是：具体失败机制未确定；新方法与原创性未建立；目标图覆盖有限；强基线及独立确认尚需完成。

下一步优先从现有结果中找到稳定、重要、可解释且可以干预的问题。不要为了赶投稿而先确定一个模块，再倒推需要什么失败故事。

# 9. 最终应形成的研究成果

理想的论文主张结构是：发现一种具体、可重复的跨图失效；提供支持该解释的控制证据；据此提出一个有实质新意的解决办法；在公平协议、强基线和未参与选择的目标上验证其效果与边界。

论文的完成以“可信地回答一个有价值的新问题”为标准，而非完成多少实验。研究路线始终围绕：**邻域信息为什么能迁移、何时失效、如何改善这种失效。**
