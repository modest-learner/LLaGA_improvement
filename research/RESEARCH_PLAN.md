# LLaGA 跨图泛化研究方案 v0.1

日期：2026-11-13。当前状态：方案审查与初步数据审计完成；尚未训练研究模型。

执行优先级修订：先按原作者数据、SimTeG 特征、公开权重、原始评分完成指标复现；再进行从头训练复现及清洁协议对照。本文第 8 节中的清洁数据构建属于后续研究阶段，不作为运行官方基线的前置条件。具体命令见 `REPRODUCTION_FIRST.md`。注意论文 v2 与 v3 的 LP 指标不同，复现时必须固定论文版本。

目标：识别跨图迁移中可复用的信息，定位稳定的失败条件，并据此提升未参与方法开发的目标图上的下游性能。保留“可信基线 → 信息归因 → 机制与边界 → 最小改进 → 外部验证”的主线；不预设最终方法一定是统一图表示或一定需要 GNN。

## 1. 先明确研究对象

将系统写为：`原始文本 X → 冻结文本编码器 E → 结合图 A 的模板 T → 可训练 Projector P → 冻结 LLM F → 预测`。

信息至少包含：中心节点语义、邻域节点语义、图决定的邻居选择/多跳聚合、模板位置/度数/掩码、类别名称与指令、预训练模型先验、源域监督。结构和语义可能互相作用，不能默认用两个独立百分比分解。

两个缩写必须分开：`ND-template` 是 Neighborhood Detail 模板；`node-description/nd-task` 是节点描述任务。主线先做 NC/LP，节点描述用于研究训练目标与跨任务迁移。

严格区分：

| 协议 | 目标图可用信息 | 结果名称 |
|---|---|---|
| 跨图零目标标签、传导式推理 | 原始文本、任务说明、类别词表、合法的可见边；模型和阈值不在目标标签上调整 | 第一阶段主协议 |
| 使用目标无标签数据优化参数/归一化统计 | 除上述输入外，还用目标图更新模型或拟合统计量 | 无监督目标域适应，单列 |
| 使用目标少量标签 | 指定数量的目标训练标签 | few-shot，单列 |
| 原始官方数据和通用权重运行 | 权重/特征训练范围未完全确认 | 工程检查或参考复现，不自动叫严格零样本 |

“零目标标签”不等于基础模型预训练从未见过论文文本。公开语料污染通常无法完全证明不存在；应记录编码器/LLM版本，并在后续加入更新或独立领域数据。

## 2. M0：冻结协议、数据审计与清洁数据视图

1. 记录代码版本、依赖、模型/tokenizer/编码器 revision、训练配置、随机种子、所有数据哈希。每次实验保存源图、目标图、源任务、目标任务、目标可见信息、特征监督来源和 checkpoint 选择规则。
2. 先做 Cora/Pubmed/Arxiv 开发实验。`Arxiv+Pubmed → Cora` 为首个方向；之后轮换留一图检验。三图都是论文图，不能代替跨领域证据。反复据 Cora 结果修改方法后，应明确它是开发目标；后续将 Products 或其他领域留作方法冻结后的确认集。
3. SimTeG 的论文方法包含下游监督微调。不能仅根据文件名断言当前文件泄漏，也不能默认它是标签无关表示。建立特征来源表：编码器权重、训练图、训练标签、原始输入文本、是否拼接人工/生成类别描述。无法追溯的特征只放参考复现。
4. 清洁主线使用同一个冻结通用 SBERT 编码器（建议从原始 title+abstract 重算，记录截断与空文本策略），跨所有图共享权重。不在目标图微调编码器；归一化若有可学习统计量，只在源图拟合。SBERT 自身可有通用语料监督，关键是没有本实验目标图标签监督。
5. 独立保存 `dataset_research/<protocol-id>/...`，保留原始文件。首先规范无向边，移除 self-pair、重复对和与可见真边冲突的负例；保留清洗映射与统计。原始复现和清洁结果不混在同一“提升”数字中。
6. LP 固定 train/validation/test 正边与负对；验证/测试正边从 message-passing 图整体移除（含反向边），然后才计算度、自环、采样树、多跳特征。训练每个正查询也需移除自身边再构建输入，或采用明确的训练边掩码方案；避免源域训练查询可见、目标推理查询不可见。
7. 普通随机负例为基础；另建度数匹配、文本相似、二跳候选等难负例评估。用完整已知边集排除伪负例并明确“未观测不一定不存在”的任务边界；候选规则不能用目标类别标签调参。
8. 同一份清洁邻接视图支撑 HO 与 ND。缓存 key 至少包含图哈希、split哈希、编码器revision、hop、归一化、自环策略、边扰动种子；改变图或文本后必须重新计算派生特征。
9. 检查源/目标文本精确重复和近重复。报告原始结果与去重敏感性结果，不能按预测正确与否删样本。验证 JSONL 的中心节点、端点和 mask 对应关系。

验收：NC 划分无重叠；LP 候选去重、自连接为零、已知伪负例为零、输入视图无查询边与保留测试正边；HO/ND 生成条件一致；特征来源可说明；目标标签不参与模型选择。当前仅完成初步审计，尚未通过全部验收。

## 3. M1：建立可比较基线

先做官方 HO+SimTeG+Vicuna 的 32 条 Cora 工程检查，仅验证加载、维度、结果完整率。公开 general model 的模型卡没有可核实的完整训练清单，不用于证明留出 Cora。

正式基线从随机初始化的 Projector 开始，在源图训练；LLM 和文本编码器冻结。每次列出 `requires_grad=True` 的参数名与数目，并检查优化器包含的参数。HO-4 使用 5 个图 token，先做低成本开发；ND-2、fanout=10 使用 111 个位置，作为独立模板复核，不能把更多 token 或计算量的收益说成纯结构收益。

| 顺序 | 训练 | 测试 | 目的 |
|---|---|---|---|
| B0 | 无图训练 | Cora NC/LP | 同一 LLM 直接读取中心/端点原始文本；固定文本预算 |
| B1 | 无目标标签 | Cora NC/LP | SBERT 对类别描述相似度；端点 cosine；LP CN/AA/RA 等结构启发式 |
| B2 | Arxiv+Pubmed，LP，中心节点/两端点 | Cora LP | Projector 语义基线 |
| B3 | 与 B2 相同预算，完整 HO | 同一组 Cora LP 对 | 邻域总收益 |
| B4 | 与 B3 相同预算，随机邻域 | 同上 | 邻域选择是否重要 |
| B5 | 源 node-description，含源类别名 | Cora NC 与 NC+原文 | 对应原方法任务迁移 |
| B6 | 源 node-description，仅原始标题/摘要、不显式拼接类别标签 | 同上 | 检验监督中的类别语义作用 |

LP 另加只用相同源图监督的端点 MLP 和 GraphSAGE；NC 的跨图基线需要共享类别描述空间/语义打分头，不能把无法输出新类别的固定源标签分类头作为有效零样本竞争者。用目标标签训练的 GNN 只能作为有监督参考，分表列出。

优先与 LLaGA、文本/嵌入强基线比较；确认方法有稳定收益后再按相同信息权限重跑 LLM-BP、UniGraph、GraphCLIP 等相关模型。其他方法若有目标域适应，要明确单列。

评分：

- NC 主指标 Accuracy 与 Macro-F1，报告每类召回、无效答案率。使用固定类别词表与说明；候选完整答案的条件对数似然可用于确定性打分，长度归一化/先验校正在源验证集预先确定；生成式严格匹配作为参考。
- LP 主指标 ROC-AUC/AP，辅以固定阈值的 balanced accuracy/F1。yes/no 若是多 token，评分完整候选续写，不硬编码单个 token ID；所有模型使用同一候选集。Hits@K/MRR 只在定义了每查询候选池与过滤规则后报告。
- 异常样本记录 error/status；不将空输出变为 no，不将异常产生的零 logit 当作正常预测。主报告给成功覆盖率；有失败时不静默删除样本宣称全测试集分数。
- 探索先 1 个种子，主结论至少 3 个训练种子，关键结果尽量 5 个；边采样/扰动种子另列。比较使用相同测试例和成对差值。节点之间相关，不能将所有节点当作独立图样本；同时报告训练种子波动、按图结果、图平均、最差图，不以单图窄 CI 证明广泛泛化。
- 小源图避免被 Arxiv 数据量淹没；固定总优化步数、任务/图采样权重和样本数。参考原论文配比单列。参数量、token、时间、显存、完整推理成本一起报告。

## 4. M2：信息归因矩阵

先在同一模板、编码器和源/目标协议内比较；避免同时更换文本编码器、LLM 与图模板。

| 实验 | 保留 | 操作及控制 | 能回答什么 |
|---|---|---|---|
| 中心/端点语义 | 中心或端点文本嵌入 | 去除邻域；另做固定 token 数的占位或重复中心控制 | 不依赖邻域能做到什么 |
| 完整邻域 | 中心、邻居、位置 | 原始合法图视图 | 完整基线 |
| 随机邻域 | 中心与数量/掩码 | 随机替换邻居，尽量匹配度数、嵌入范数等分布 | 正确邻居选择的价值 |
| 文本检索邻域 | 中心与数量 | 同一文本池按语义相似度检索，不用真实边 | 图是否主要充当相关文本检索器 |
| 邻域词袋/无位置 | 同一批真实邻居文本 | 打乱邻域与结构位置的对应；训练匹配控制 | 位置/路径是否超出语义集合提供信息 |
| 度保持重连 | 文本与尽可能固定的度 | 重连后重做采样/聚合，并报告实际统计变化 | 超出度分布的连接模式作用 |
| 文本置换 | 图与文本边际分布 | 节点间置换文本并重算全部多跳特征 | 语义与结构对应关系的作用 |
| 结构探针 | 可见图 | 常量特征/共享结构特征；多个独立随机特征种子 | 无语义情况下此架构可提取的结构信息 |
| 标签说明控制 | 输入图文本 | 类别名称改写；若改成代码必须在 prompt 明示代码与语义映射 | 输出词表和语义先验的影响 |

每个核心消融同时区分两种实验：冻结完整模型只在测试时干预（依赖/脆弱性），在对应输入条件下从头训练 Projector（该信息可支持的能力）。只做测试破坏不能推出训练时该信息没有用。

不能将全零文本后的低分解释为“结构无效”：HO 对常量特征可能退化，变化还可能来自分布外输入。不能把打乱邻居后的低分解释为纯拓扑理解：也破坏了邻域语义与目标的关联。随机邻域、语义检索邻域、保留节点集合的位置干预应配合使用。

主统计量包括 `完整 − 中心`、`真实邻域 − 随机邻域`、`真实邻域 − 语义检索邻域`。这些是指定干预下的性能差，不是普适“结构贡献百分比”。结构/文本 2×2 的差分交互可以报告，但依赖干预定义与指标尺度。

## 5. M3：Projector 机制及可证伪假设

| 假设 | 干预 | 支持/反驳信号 |
|---|---|---|
| P 主要完成共享文本空间到 LLM 的接口适配 | 随机 P、源中心训练 P、源完整训练 P；相同维度/模板下迁移到完整目标输入 | 中心训练 P 已接近完整 P 支持接口解释；特定结构下稳定差距说明仍有邻域适配 |
| 任务监督决定迁移，而非抽象图统一 | LP-only、NC-only、description-with-label、description-without-explicit-label、混合任务，固定预算 | 建立源任务→目标任务矩阵；含标签描述的优势需按监督信息解释 |
| 迁移依赖统一编码器坐标与尺度 | 使用同一编码器；共同正交变换后重训 P 作可逆控制；只变换目标作坐标错配诊断 | 区分坐标兼容性与语义质量，避免将任意换编码器后的掉分称为机制证明 |
| 跨域失败来自源邻域规律/尺度不匹配 | 单源、多源、图平衡训练；不同 hop 与归一化；目标分层误差 | 在多个目标与种子上可重复的失败模式 |
| LLM 预训练知识提供额外价值 | 直接原文 LLM、类别语义检索、同输入小解码器；必要时额外做同架构随机冻结 LLM 控制并重训 P | 量化具体系统组件增益；不把小模型差距直接等同于“推理能力” |

跟踪输入/P输出范数、有效秩、中心与各 hop 的变化、类别描述相似度、跨图探针等。CKA、t-SNE、注意力图只作描述证据；用移植、删除/替换、反事实输入与重新训练验证行为后果。Projector 形状相同才可移植；SimTeG 和 SBERT 输入维度不同，不能直接互换权重。

单次结果只生成假设。预先写出什么结果会推翻它，不追求“证明原始模型一定学到了图结构”。

## 6. M4：定位边界并选择最小改进

压力轴：图度数/密度变化、邻居语义相似度变化、低文本质量/缺失/改写、hop 深度、难负例、源任务变化、类别名称改写。标签同配性只能用于事后分层分析，不作为零目标标签推理时的可用特征。

合成可控图可用于区分语义可解、结构可解、两者联合可解的任务，但改变结构可能改变真实标签：只有明确定义的生成机制下才可声称标签不变。不能默认每种重连/边删减都应预测不变。

按证据选择一个改动：

- 邻域在某些目标系统性有害：以度数、文本相似度、各 hop 分歧等无标签信号学习可退回中心语义的门控，所有参数在源图训练；比较固定 hop 权重、简单均值、同参数量 MLP 等控制。
- 中心语义过强、难负例失败，而可用图结构确实有增量价值：加入针对端点关系的结构摘要或多尺度关系表示；用固定统计特征基线检验新模块是否必要。
- 编码器/特征尺度转移是主瓶颈：优先做尺度规范化、共享语义对齐或任务条件映射；先与简单 LayerNorm/标准化比较。
- 任务/图大小偏置是主瓶颈：先做源图/任务平衡、图留一验证和训练目标重权，不直接堆叠新网络。

最小方法必须在同一清洁协议下超过完整 LLaGA 和强文本基线，并改善已定位失败子集；保留中心基线的收益与最差图风险。设置源图选择规则和最低有意义提升，再做目标确认。收益只出现在随机负例、一个种子或一个目标，不进入“泛化改进”结论。

“结构自适应”“统一图表示”“图文本对比学习”已有相关工作，不直接视为创新点。最终贡献需要是新的可检验机制、由机制推导的方法和严格外部证据。

## 7. M5/M6：扩展到跨领域、图分类和开放任务

Products 可延期。开发阶段先三张论文图；方法冻结后加入 Products 与至少另一个合适领域/结构分布的目标图。规模过大时先采用预先固定、无标签驱动的候选/子图抽样，保存采样规则；样本结果不冒充完整 Products 基准。

图分类需要独立的多图数据集、图级标签、图级 train/val/test/领域划分，以及可扩展的图读出/多中心采样。把一张引用图的 ego-graph 当成“独立图分类”不能替代真正跨域图级验证。节点级、边级、图级任务输入预算需分别定义。

开放问答应区分可自动验证的关系/属性问题和主观描述。优先用结构/事实核验；LLM-as-judge 需固定 rubric 并用人工抽样校准。生成解释本身不是机制证据。
